0. First — What is a Neural Network?

Every AI model in this guide is built from neural networks — programs that learn patterns from data, inspired (loosely) by how brain neurons connect.

The Core Idea

A neural network takes an input (like a DNA sequence), passes it through layers of simple math operations, and produces an output (like "the next letter is probably T"). Each layer transforms the data a little, extracting increasingly complex patterns.

The magic: the network learns what transformations to apply by seeing billions of examples during training. It adjusts its internal numbers (called weights — there are billions of them) until it gets good at the task.

Analogy: Think of a neural network like a factory assembly line. Raw materials (DNA letters) enter at one end. Each workstation (layer) performs a specific operation — checking for patterns, combining information, making decisions. The product that comes out the other end is the prediction. The factory learns to configure each workstation by practicing on millions of examples.
Key idea: All the architectures below (Transformers, SSMs, CNNs) are just different designs for these "workstations" — different ways to process and transform data at each layer. The question is always: what's the best way to look at the input data?

1. Convolution — Sliding a Window to Find Patterns

Convolution is the oldest and simplest technique Evo 2 uses. It's the backbone of CNNs (Convolutional Neural Networks), used in image recognition since the 1990s.

How It Works

Imagine you have a magnifying glass of a fixed size (say, 7 letters wide). You slide it across the DNA sequence, one position at a time. At each position, the magnifying glass checks: "Does the pattern under me match something important?"

The "magnifying glass" is called a filter (or kernel). It's a small set of learned numbers that detect a specific pattern. Multiple filters run in parallel, each looking for a different pattern.

Analogy: Like a spell-checker that slides across your text, checking each word against its dictionary. It can only see a few characters at a time — it catches typos in "teh" but can't tell if your overall essay makes sense.
Strength: Very fast and efficient. Great at finding local patterns (codons, motifs).
Weakness: A small window can't see long-range relationships. A 7-letter filter can never detect that a gene 10,000 letters away is related.

2. Attention — Letting Every Position Talk to Every Other

The Transformer architecture (2017) revolutionized AI. It powers ChatGPT, AlphaFold, DNABERT, and most modern AI models. Its core innovation: attention.

How It Works

Instead of sliding a small window, attention lets every position in the sequence look at every other position and decide which ones are most relevant. For each position, it computes a "relevance score" with all other positions, then uses those scores to gather information.

This happens through three learned projections — called Query (what am I looking for?), Key (what do I contain?), and Value (what information do I carry?). Each position's Query is compared against all Keys to produce attention scores, then those scores weight the Values to produce the output.

Multi-head attention runs this process multiple times in parallel (e.g., 32 "heads"), each looking for different types of relationships. One head might focus on nearby letters, another on distant regulatory elements.

Analogy: Imagine a classroom discussion where every student can hear every other student simultaneously. Each student (position) decides who's saying the most relevant things (attention scores) and takes notes accordingly. "Multi-head" means multiple parallel discussions happening at once, each on a different topic.
Strength: Can capture relationships between ANY two positions, no matter how far apart. This is why it's so powerful for understanding language and biology.
Weakness: Comparing every position to every other position costs O(n²) — quadratic. For a 1-million-letter genome, that's 1 trillion comparisons per layer. Very expensive!

3. State-Space Models (SSM) — Remembering As You Read

SSMs (including Mamba and Hyena) are the newest architecture family (2023-2024). They're designed to handle very long sequences efficiently — exactly what genomics needs.

How It Works

An SSM processes the sequence one element at a time, maintaining a compact "memory" (called the state) that summarizes everything it has seen so far. At each step, it updates this memory based on the new input, then uses the memory to produce an output.

The key insight: this is mathematically equivalent to a very long convolution, but computed much more efficiently. Instead of storing a filter the size of the entire sequence, it uses a compact recurrence formula.

Hyena (used in Evo 2) adds data-dependent gating — the input itself controls how information flows through the system. This makes it more expressive than a simple SSM while keeping the efficiency.

Analogy: Think of reading a novel and keeping a mental summary as you go. You don't remember every word you've read, but you maintain a compressed understanding. When you read "the detective revealed the killer was the butler," your mental state updates dramatically. SSMs work the same way — a compact state that evolves as it processes each position.
Strength: Processes sequences in O(n log n) time — much faster than attention's O(n²). Can handle 1M+ positions. During generation, uses O(1) memory per step (no growing cache).
Weakness: The compressed state can't perfectly represent all pairwise relationships the way attention can. Some long-range interactions may be missed.

4. Why Evo 2 Combines Them — The Hybrid Approach

Now you understand the trade-offs. Evo 2's insight: use each technique where it's strongest.

The StripedHyena-2 Recipe

Layer TypeWhat It Does% of LayersSpeed
Hyena Short ConvDetects tiny local patterns (~7 letters): codons, dinucleotides28%Very fast
Hyena Medium ConvDetects promoters, regulatory regions (~128 letters)28%Fast
Hyena Long ConvCaptures chromosome-scale patterns (full sequence)28%Fast (FFT)
AttentionExact global comparisons between all positions16%Slower (O(n²))

The layers follow a repeating cycle: Short → Medium → Long → Attention. This way:

  • ~84% of computation is sub-quadratic (fast Hyena layers)
  • ~16% is attention (expensive but precise global view)
  • The model gets multi-scale understanding: local → medium → global → exact pairwise
Analogy: Like editing a book. First, a copy editor checks spelling and grammar (short conv — local). Then a section editor reviews paragraph flow (medium conv). Then a structural editor checks chapter connections (long conv). Finally, a senior editor does a full cross-reference check (attention — expensive but thorough). You don't need the senior editor at every step — just occasionally for the big picture.
Result: Evo 2 can process sequences up to 1 million nucleotides in a single pass — something a pure Transformer model couldn't do because of the quadratic cost. This is why it can understand entire chromosomes, not just individual genes.
